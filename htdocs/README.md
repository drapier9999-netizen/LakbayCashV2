# LakbayCash — Premium Filipino Loan App

A complete, production-ready, mobile-first loan application built with PHP + MySQL, designed specifically for Filipino users with a premium fintech aesthetic.

## Quick Start

1. Upload `htdocs/` contents to your web root
2. Create a MySQL database
3. Import `htdocs/database.sql`
4. Edit `htdocs/config.php` with your DB credentials
5. Visit your domain — the app runs automatically

## Admin Panel
